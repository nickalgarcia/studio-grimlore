## Security

- [x] **S1 — Critical: server actions are unauthenticated.**
  All nine actions in `src/app/actions.ts` (`getLiveSessionResponse`, `getContextualIdeas`,
  `getInspiration`, `getRuleInfo`, `getNpc`, `getCampaignSummary`, `getSessionRecap`,
  `getSessionPrep`, `parseObsidianSessionAction`) are public POST endpoints. Their IDs ship in the
  client bundle, which loads before the auth gate. Anyone can call them and spend the Anthropic key;
  `getLiveSessionResponse` accepts arbitrary messages + system context, so it is effectively an open
  Claude proxy.
  *Fix:* add `src/firebase/require-user.ts` (server-only) that takes an ID token, calls
  `getAdminAuth().verifyIdToken`, checks the allowlist from S2, and throws otherwise. Every action takes
  `idToken` as its first argument; clients pass `await user.getIdToken()`. Share the helper with the route.

- [x] **S2 — High: anyone can sign up.**
  `auth-gate.tsx` has a public Sign Up tab and nothing server-side limits who may use the AI. After S1,
  a stranger could still register and use it.
  *Fix:* turn off new-account creation in Firebase Auth settings; remove the Sign Up tab; add an
  `ALLOWED_UIDS` (or `ALLOWED_EMAILS`) env var checked in `requireUser`.
  *Code done. Owner still to do:* untick "Enable create (sign-up)" in Firebase console →
  Authentication → Settings → User actions; set `ALLOWED_UIDS` in `.env.local` and in Vercel.

- [ ] **S3 — High: a Gemini API key is in git history.**
  `.env` was committed in `16a1204` (Dec 2025) with `GEMINI_API_KEY=AIza…`. Later commits emptied it,
  but history keeps it, and it's on GitHub.
  *Fix:* revoke/rotate that key in Google Cloud now (rotation is what actually matters). Optionally
  purge history with `git filter-repo --path .env --invert-paths` + force push — owner decision.

- [ ] **S4 — High: vulnerable Next.js.**
  `next@15.5.7` has critical/high advisories (server-action source exposure, RSC deserialization DoS,
  image-optimizer DoS). `npm audit --omit=dev` also flags postcss, and transitive issues via
  `firebase-admin@12` and `patch-package`.
  *Fix:* bump `next` to the latest 15.5.x patch, `npm audit fix` (non-breaking), then plan
  `firebase-admin` 12 → current major. Remove `patch-package` (no `patches/` dir exists).

- [ ] **S5 — Medium: no input limits or rate limiting on AI calls.**
  There are zero `.max()` constraints across the flow schemas, and the co-pilot resends the whole
  transcript every turn.
  *Fix:* `.max()` on every string/array in `src/ai/flows/*`; cap total request size in the route;
  simple per-uid rate limit; set a monthly spend limit on the Anthropic workspace as a backstop.

- [ ] **S6 — Medium: build guards disabled.**
  `next.config.js` has `typescript.ignoreBuildErrors` and `eslint.ignoreDuringBuilds`. Types pass now,
  so turn the TS flag off. Install `eslint` + `eslint-config-next` so `npm run lint` works, then drop
  the ESLint flag.

- [ ] **S7 — Low: add security headers.** `headers()` in `next.config.js`: `X-Content-Type-Options:
  nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `frame-ancestors 'none'`, and a CSP
  allowing self + Firebase/Google auth domains.

- [ ] **S8 — Low: remove dead attack surface.** `images.remotePatterns` allows placehold.co / unsplash /
  picsum for an unused `placeholder-images` module — delete both (shrinks image-optimizer exposure).
  Delete `cleanup.sh` (`rm -rf .git` + force push).

- [ ] **S9 — Low: Firestore rules hardening.** Add `campaignId` checks to `npcs`/`factions`; drop rule
  blocks for unused `plotHooks`/`encounterIdeas`/`npcConcepts`; add basic size guards
  (e.g. `request.resource.data.notes.size() < 200000` on `liveSession`).

- [x] **S10 — Low: lockfile drift.** `npm ci` fails (`Missing: picomatch@4.0.7 from lock file`).
  Run `npm install`, commit the lockfile, so Vercel builds are reproducible.

## UI / UX

- [ ] **U1 — High: one click erases a live session.** The unlabeled ↺ icon in Table calls
  `clearSession()` with no confirm. It wipes notes + transcript, and the debounced persist then
  overwrites `liveSession/current` — unrecoverable. Also `startedAt` survives in Firestore (merge write
  omits it), so the old clock comes back on reload.
  *Fix:* AlertDialog confirm (or an Undo toast that restores state); write `startedAt: deleteField()`
  on clear; consider archiving the old doc instead of overwriting.

- [ ] **U2 — High: any failed Firestore write crashes the app.** `FirebaseErrorListener` throws in
  render on every `permission-error`, and there is no `app/error.tsx` / `global-error.tsx`. All write
  failures (quota, oversized doc, bad field) are reported as permission errors. Mid-session that's a
  full-screen crash.
  *Fix:* in production, toast instead of throw; add `src/app/error.tsx` with a "reload, your notes are
  saved" recovery; pass the real error code through.

- [ ] **U3 — Medium: close-session dead ends.** "Regenerate" only sets `recapPreview` to null, leaving a
  blank page with "Back to session". A failed recap generation lands on the same blank page.
  *Fix:* Regenerate re-calls `handleCloseSession`; render an error state with Retry.

- [ ] **U4 — Medium: party dock is built for five, the party is seven.** `FITS_WITHOUT_SCROLL = 5`, so
  the dock always scrolls sideways at the table and hides two players.
  *Fix:* compact plate layout that fits 7–8 across (≈150px min, stats in 2×2), or two rows.

- [ ] **U5 — Medium: co-pilot blocks typing while it answers.** The textarea is `disabled` during
  streaming (also drops focus), and there's no Stop button though abort is wired.
  *Fix:* keep the textarea enabled, disable only Send; add a Stop button calling `abortRef.abort()`.

- [ ] **U6 — Medium: text too small for the table.** ~60 uses of 8.5–10.5px text; HP/AC/PP stats are
  10–10.5px. *Fix:* 11px floor for anything read mid-session; optional "table scale" toggle that bumps
  the root size.

- [ ] **U7 — Medium: desktop-only cockpit.** Table is a fixed `1fr / 396px` grid in an `h-screen
  overflow-hidden` shell with no breakpoints. *Fix:* under ~1100px, collapse the co-pilot into a
  slide-over (Sheet) with a toggle in the status bar.

- [ ] **U8 — Low: unbounded transcript.** Full history is resent each turn (cost grows) and stored in one
  doc (Firestore's 1 MiB limit → with U2, a crash). *Fix:* send the last ~12 turns; cap stored messages.

- [ ] **U9 — Low: semantics/polish.** Mode switcher and Scene/Combat toggle → `role="tablist"`/`tab` +
  `aria-selected` (or `aria-pressed`). Show "Ctrl K" on non-Mac. Add `autoComplete="email"` /
  `"current-password"` to the sign-in form.
